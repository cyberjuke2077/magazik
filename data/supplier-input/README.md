# Входной список MPN

В эту папку локально кладётся утверждённый список артикулов заказчика.
Файлы заказчика не коммитятся.

Минимальный CSV:

```csv
MPN
STM32F103C8T6
ADG212AKNZ
```

Поддерживаются `.csv`, `.xlsx` и `.xls`, заголовки `MPN`, `Part Number`,
`Артикул` и `型号`. Столбец бренда необязателен.

Проверка входа без БД и сетевых запросов:

```bash
npm run enrichment:run -- --dry-run --limit 3 --no-tui
```

После проверки входа выполняется ограниченный пилот с `--limit 3` на локальной БД.
