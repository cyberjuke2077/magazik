# Главная: локальный вариант фотографий и цвета

## Решение владельца

После возврата прежней композиции владелец запросил разные подходящие фото,
менее тусклые цвета и немного прозрачности. На предложение загрузить шесть
готовых изображений в R2 и сделать push ответил: «Пока оставить только локально».
Эта граница отменяет прежнее разрешение на push для данной правки.

## Сделано

Изменён только HeroSlider: те же шесть карточек, размеры, порядок, тексты,
ссылки и горизонтальная прокрутка. Первая карточка стала графитовой, цветные
пастельные заливки заменены нейтральными полупрозрачными подложками текста.
Шапка, категории, товары, общие CSS и остальная главная не менялись.

Built-in imagegen создал шесть самостоятельных сюжетов:

- bom: стол комплектовщика со спецификацией и пакетами компонентов;
- mpn: крупный план отдельной микросхемы и пинцета;
- alternatives: два корпуса и штангенциркуль;
- datasheet: технический чертёж корпуса на бумаге;
- supply: катушка с компонентами в ленте;
- makers: кремниевая пластина.

Это декоративные изображения услуг, не фото конкретных товарных SKU.
Оригиналы и полный набор prompts: `.tmp/home-photos/manifest.json`,
`.tmp/home-photos/{bom,mpn,alternatives,datasheet,supply,makers}.png`.
Копии для preview: `public/storefront/editorial-v1/`. Обе папки исключены из Git.
Исходники генерации также сохранены в штатной папке Codex generated_images.

## Граница публикации

Только локальный кандидат. R2, production и remote Git не менялись.
Код с локальными путями нельзя отправлять в remote в этом состоянии:
на другом checkout этих изображений нет. Перед возможной публикацией нужны
явное разрешение владельца, R2 URL вместо локальных путей и новая проверка.

## Проверки

TypeScript, ESLint и git diff --check прошли. Четыре существующих E2E контракта главной
и storage прошли на desktop/mobile. Все шесть картинок загрузились на 1440
и 390 px, переполнения документа нет. Оба viewport screenshot просмотрены.
Композиция страницы и шесть заголовков сохранены.
Два визуальных эталона главной обновлены и просмотрены. Production build
повторно не запускался: пользователь оставил изменение локальным.

Preview: http://127.0.0.1:3000/.
