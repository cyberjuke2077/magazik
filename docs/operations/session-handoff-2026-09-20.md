## Товарная база

Настроенный `ENRICHMENT_INPUT_DIR` указывает на `data/supplier-input`; папка
содержит только `.gitkeep`. Путь к настоящим исходникам запрошен у владельца,
ответ пока не получен. `data/parsed` содержит старые выгрузки, они не приняты
как текущий набор поставщика. Реальный live-пилот и массовое наполнение
не запускались, новые товарные карточки этим проходом не созданы.

Проверен штатный input-only маршрут:

```sh
npm run enrichment:run -- --input-dir data/trial-supplier --dry-run --limit 3 --no-tui
```

Результат: 1 CSV, 3 строки, 3 уникальных MPN, без пропусков, БД и внешних API.
Это smoke-проверка импортера, не обработка клиентского набора.
Исторические 11 файлов / 75 706 строк / 67 200 MPN нужно пересчитать заново.

После получения пути: dry-run по реальным файлам, подтвердить состав и числа,
выбрать отдельную локальную БД каталога, выполнить live-пилоты 1 и 5 MPN,
проверить точность MPN/бренда, сохранённые поля и unresolved. Затем решать
объём следующего запуска. Не писать enrichment в `emg_readiness`: это fixture
для E2E. Windows-маршрут: [инструкция](../windows-parser-setup.md).
