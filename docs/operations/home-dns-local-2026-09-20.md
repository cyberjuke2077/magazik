# Главная по скриншоту DNS: локальный кандидат v2

## Запрос и граница

Владелец отклонил серый фотографический вариант: «все сливается», приложил
скриншот DNS, затем уточнил: «продолжай, мне нужна главная страница как у днс».
Работа продолжена по конкретному скриншоту. Предыдущее указание «Пока оставить
только локально» остаётся в силе: без push, R2, production и изменения БД.

## Реализация

- Сервисные карточки: отдельные цельные фоны, тёмный текст, крупные предметы
  с прозрачным фоном в нижнем правом углу. Убраны серые фото-полосы, blur и
  тёмная первая карточка. Тексты, ссылки, размеры и порядок сервисов сохранены.
- Built-in imagegen создал 9 отдельных PNG с настоящим alpha: 6 для сервисов,
  3 для доступных в локальном каталоге разделов. Это иллюстрации услуг/категорий,
  не фотографии конкретных товарных SKU.
- Категории: компактные изображения, ссылки на подкатегории; для разделов без
  детей показаны реальный счётчик и ссылка на раздел. На mobile горизонтальный
  ряд доступен целиком, третья категория больше не скрыта.
- Бренды перенесены между категориями и товарами, как в референсе.
- Товары: более спокойный фон секции, компактный заголовок, без декоративного
  eyebrow. Desktop-сетка заполняет доступную ширину; mobile использует
  горизонтальный ряд. Вариант ProductCard `home` меняет только оформление
  главной, стандартный вид сохраняется в остальных местах.
- Изображения ProductCard пропускают pointer events к ссылке: клики по ним
  больше не блокируются. Корзина, цены, данные и API не менялись.
- Шапка, footer и остальные страницы не перестраивались. Вымышленные новости,
  акции и рекламные предложения не добавлялись.
- Общая сетка главной получила отступы 24 px на промежуточных desktop-ширинах
  через локальный CSS Module. На других страницах эти стили не действуют.
- `sizes` миниатюр соответствует 104 px desktop / 156 px mobile; исчез запрос
  избыточно крупных вариантов при ширине 1024 px.

## Локальные артефакты

Готовые PNG: `public/storefront/objects-v2/` (исключены из Git).
Копии и точные prompts: `.tmp/home-objects/manifest.json` и
`.tmp/home-objects/category-prompts.json`; копии PNG лежат рядом.
Скриншоты: `.tmp/home-objects/shelf.png`, `home-1440.png`, `home-390.png`.
Первый вариант `editorial-v1` сохранён локально, но больше не используется.

Перед возможным push нужны отдельное разрешение владельца, публикация новых
файлов в R2 и замена локальных URL. Без этого другой checkout не воспроизведёт
страницу. Нельзя считать локальный commit разрешением на публикацию.

## Проверки

34 существующих storefront E2E проверки прошли на desktop/mobile, включая
8 визуальных assertions. После финальной настройки отступов отдельно
проверены 1024/1440 px и повторно обновлены два эталона главной.
Также вручную проверены 320/390/768 px, отсутствие overflow, шесть сервисных
ссылок и переход по изображению товара. Новые PNG имеют реальную прозрачность
(alpha min 0, max 255). Финальные TypeScript, ESLint и git diff --check прошли.
Полный buyer suite и production build повторно не запускались.

Один ручной диагностический скрипт завис на networkidle/декодировании слишком
больших миниатюр. Проверка переведена на готовность конкретного контента,
sizes исправлен; повторная проверка завершилась успешно.
Preview содержит 3 тестовых товара и 3 категории, не наполненный каталог.

Preview: http://127.0.0.1:3000/.
