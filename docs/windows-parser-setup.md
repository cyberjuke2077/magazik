# Парсер Electromagaz на чистой Windows

Инструкция рассчитана на человека, который раньше не работал с командной
строкой. Команды вручную вводить не нужно: установка и запуск выполняются через
два файла в папке `windows`.

## Что будет установлено

- Node.js LTS - запускает парсер.
- Docker Desktop - держит локальную PostgreSQL с результатами.
- Зависимости проекта - ставятся командой `npm ci` внутри установщика.
- CloakBrowser с Playwright - открывает ChipDip. BrowserAct не используется.

Парсер пишет карточки только в локальную PostgreSQL. Фотографии остаются
отдельными кандидатами-ссылками: бинарные файлы в БД не попадают, неочищенные
фото в R2 не загружаются.

PDF-даташиты также не хранятся в PostgreSQL. После проверки настоящий PDF
загружается в Cloudflare R2, а в БД остаются только название, язык, размер и
публичная ссылка.

## 1. Получить проект через GitHub Desktop

1. Откройте в браузере `https://desktop.github.com/`.
2. Нажмите `Download for Windows`, откройте скачанный файл и установите
   GitHub Desktop.
3. Запустите GitHub Desktop и нажмите `Sign in to GitHub.com`.
4. В браузере войдите в GitHub и подтвердите открытие GitHub Desktop.
5. В GitHub Desktop выберите `File` -> `Clone repository`.
6. Во вкладке `URL` вставьте:
   `https://github.com/cyberjuke2077/magazik.git`.
7. В `Local path` укажите простую папку, например `C:\electromagaz`.
8. Нажмите `Clone`.

Если GitHub пишет, что доступа нет, владелец репозитория должен сначала добавить
ваш GitHub-аккаунт в Collaborators. Пароли и ключи в репозитории не хранятся.

## 2. Первичная установка

1. В GitHub Desktop откройте меню `Repository` -> `Show in Explorer`.
2. В проводнике откройте папку `windows`.
3. Дважды нажмите `INSTALL.cmd`.
4. Если Windows SmartScreen покажет предупреждение, нажмите `Подробнее`, затем
   `Выполнить в любом случае`.
5. Разрешите установку в системном окне Windows.
6. Если установщик просит перезагрузить компьютер - перезагрузите Windows.
7. После перезагрузки откройте Docker Desktop, примите условия и дождитесь
   надписи `Engine running`.
8. Снова дважды нажмите `windows\INSTALL.cmd`.
9. Дождитесь зелёной строки `Готово`.

Установщик создаст локальный `.env` из безопасного шаблона. Этот файл Git не
видит. Не отправляйте его в чат и не добавляйте вручную в GitHub.

## 3. Первый запуск

1. Скопируйте все Excel/CSV-файлы заказчика в одну отдельную папку. Можно
   оставить исходные имена файлов.
2. Дважды нажмите `windows\RUN-PARSER.cmd`.
3. В открывшемся окне выберите папку с файлами заказчика.
4. В меню введите `1` и нажмите Enter.

Пункт 1 только проверяет файлы. Он не открывает сайты и не пишет в БД. Для
текущего набора правильный контрольный результат:

- файлов - 11;
- строк - 75 706;
- пропущено строк - 17;
- уникальных артикулов - 67 200.

Если цифры отличаются, не запускайте полный проход: сначала проверьте, та ли
папка выбрана и все ли файлы скопированы.

## 4. Живой пилот

1. Снова откройте `RUN-PARSER.cmd`.
2. Выберите пункт `2 - Пробный запуск на 1 товаре`.
3. Дождитесь шкалы `100%` и зелёного счётчика `ChipDip найдено` или `LCSC
   найдено`.
4. Затем выполните пункт `3 - Пробный запуск на 5 товарах`.
5. Пункт `7` показывает, что реально записано в локальную БД.

Один запрос к ChipDip намеренно занимает примерно 30-60 секунд. Задержка нужна,
чтобы ChipDip реже блокировал машину. Если появилась CAPTCHA или блокировка, не
перезапускайте процесс много раз подряд.

## 5. Рабочий запуск

- Пункт `4` обрабатывает пакет из 100 новых товаров. Это основной безопасный
  режим: после проверки запускайте следующий пакет.
- Пункт `5` запускает весь остаток. Для 67 тысяч позиций это может занять недели,
  поэтому меню требует фразу `ПОЛНЫЙ ЗАПУСК`.
- Пункт `6` продолжает прерванный запуск.
- `q` или `Ctrl+C` безопасно заканчивает текущую операцию. Уже сохранённые
  карточки не теряются.

Не выключайте Docker Desktop во время работы. Экран Windows можно заблокировать,
но компьютер не должен уходить в сон.

## 6. Настроить и загрузить даташиты

Настройку R2 делает владелец Cloudflare один раз на каждой машине:

1. В Cloudflare Dashboard откройте `R2` -> `Manage R2 API Tokens` и создайте ключ
   с правом записи только в bucket Electromagaz.
2. Дважды нажмите `windows\SETUP-R2.cmd`.
3. Последовательно вставьте S3 API endpoint, имя bucket, Public Development URL,
   Access Key ID и Secret Access Key. Секрет при вводе скрыт.
4. Не отправляйте ключи в чат и не добавляйте `.env` в GitHub.
5. В `RUN-PARSER.cmd` сначала выберите пункт `9`. Он только покажет очередь и
   ничего не скачает.
6. Выберите пункт `10`, введите `ЗАГРУЗИТЬ PDF`. За один запуск обрабатывается не
   больше 100 товаров.

Загрузчик принимает только HTTPS и настоящий PDF до 25 МБ. HTML-страницы,
внутренние адреса и подозрительные перенаправления отклоняются. Старая ссылка не
удаляется, если новый файл не прошел проверку или не загрузился в R2.

## 7. Получать общий код и второй мозг

Перед каждой рабочей сессией:

1. Откройте GitHub Desktop.
2. Выберите репозиторий Electromagaz.
3. Нажмите `Fetch origin`.
4. Если появилась кнопка `Pull origin`, нажмите её.
5. Только после этого запускайте `RUN-PARSER.cmd`.

Документы, планы и инструкции лежат в том же private-репозитории и не мешают
Vercel: Vercel собирает приложение из кода, а Markdown-файлы остаются обычной
документацией.

## 8. Фотографии и видеокарта

Текстовый парсер и локальная модель фотографий - два отдельных процесса.
Проверенный в этой инструкции launcher запускает только сбор карточек и очереди
картинок. Очистка watermark выполняется worker-ом Florence-2-large 0.77B +
Big-LaMa из `tools/watermark-removal` на NVIDIA.

До запуска image worker нужны:

- свежий NVIDIA Driver;
- доступ к R2 через `R2_ACCESS_KEY_ID` и `R2_SECRET_ACCESS_KEY`;
- ручной пилот минимум на одном изображении;
- подтверждение, что очищенная фотография не испорчена.

Неочищенный оригинал запрещено загружать в R2. Массовый image worker не входит в
первый запуск парсера - его настраиваем отдельно после проверки Windows-машины и
получения R2-ключей.

## Частые ошибки

### `Docker не запущен`

Откройте Docker Desktop через меню Пуск, дождитесь `Engine running`, затем снова
откройте `RUN-PARSER.cmd`.

### `winget не найден`

Откройте Microsoft Store, найдите `App Installer`, установите или обновите его и
снова запустите `INSTALL.cmd`.

### ChipDip заблокировал запросы

Остановите запуск клавишей `q`. Не меняйте задержки на меньшие. Продолжите позже
через пункт 6. Если блокировки повторяются, нужна отдельная настройка residential
proxy, а не частые перезапуски.

### Окно сразу закрылось

Запустите `RUN-PARSER.cmd` ещё раз. При ошибке окно остаётся открытым и показывает
код. Сфотографируйте весь текст ошибки, не только последнюю строку.
