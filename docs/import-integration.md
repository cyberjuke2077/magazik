# Интеграция импорта ChipDip в админку

## Что сделано

Интегрирован существующий парсер ChipDip в админ-панель для запуска импорта прямо с сайта.

## Созданные файлы

### 1. `src/lib/services/import-service.ts`
Сервис управления импортом:
- Singleton класс для фонового импорта
- Real-time статистика (total, imported, updated, failed, duration)
- Логи последних 100 записей
- Использует существующий парсер из `src/lib/parser/`
- Rate limiting: 1 запрос/2 секунды
- Транзакции для каждого товара

**Основные методы:**
- `startImport(settings)` - запустить импорт
- `stopImport()` - остановить импорт
- `getStatus()` - получить статус и логи

### 2. `src/app/api/admin/import/route.ts`
API endpoints:
- `GET /api/admin/import` - получить статус импорта
- `POST /api/admin/import` - запустить/остановить импорт

**Пример запроса:**
```json
POST /api/admin/import
{
  "action": "start",
  "settings": {
    "maxProducts": 100,
    "updateExisting": true,
    "loadImages": true,
    "loadSpecs": true
  }
}
```

### 3. `src/components/admin/admin-import.tsx` (обновлён)
UI компонент с real-time обновлениями:
- Кнопки Start/Stop
- Прогресс-бар с процентами
- Статистика: всего/импортировано/обновлено/ошибок/время
- Настройки: лимит товаров, обновление существующих, загрузка изображений/спецификаций
- Логи с цветовой индикацией (success/error/warning/info)
- Polling каждые 2 секунды при активном импорте

## Как использовать

1. Откройте админ-панель: http://localhost:3000/account
2. Перейдите в раздел "КАТАЛОГ" → "Импорт данных"
3. Настройте параметры импорта:
   - Лимит товаров (по умолчанию 100)
   - Обновлять существующие товары
   - Загружать изображения
   - Импортировать спецификации
4. Нажмите "Запустить импорт"
5. Наблюдайте за прогрессом в real-time
6. При необходимости нажмите "Остановить"

## Технические детали

**Парсинг:**
- Использует Cheerio для HTML парсинга
- Playwright для сложных страниц (если нужно)
- Rate limiter: 1 req/2 sec (уважительно к серверам ChipDip)
- Retry logic: 3 попытки с exponential backoff

**База данных:**
- Транзакции для каждого товара
- Upsert логика (создание или обновление)
- Автоматическое создание категорий и производителей
- Связи: Product → Manufacturer, Category, Images, Specifications, Datasheets

**Производительность:**
- 100 товаров ≈ 3-4 минуты (с rate limiting)
- Память: <100MB
- Фоновый процесс не блокирует UI

## Что импортируется

Для каждого товара:
- ✅ Название
- ✅ Артикул (partNumber)
- ✅ SKU
- ✅ Производитель (создаётся автоматически)
- ✅ Категория (создаётся автоматически)
- ✅ Описание
- ✅ Вес
- ✅ Изображения (массив URL)
- ✅ Спецификации (ключ-значение)
- ✅ Datasheets (PDF документация)
