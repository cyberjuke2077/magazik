# Цели проекта

## Сейчас

Главный текущий приоритет - полный редизайн публичной витрины по плотной
коммерческой композиции DNS Shop с сохранением бренда и бизнес-логики Electromagaz.

Порядок: регрессионный контур, дизайн-фундамент, общая оболочка, каталог, товар,
список запроса и формы, главная, публичные страницы, финальная проверка.
