# Electromagaz - описание проекта

## Что это

Интернет-магазин электронных компонентов и микроэлектроники.
Каталог с тысячами позиций: резисторы, конденсаторы, реле, датчики, контроллеры, разъёмы и т.д.

Прод: https://electromagaz.vercel.app

## Целевая аудитория

- **Инженеры-электронщики** - ищут конкретный компонент по маркировке (MPN), проверяют наличие, смотрят даташит
- **Радиолюбители** - мелкие заказы, интересует наличие и цена
- **Мелкосерийное производство** - оптовые цены, заявки на КП (коммерческое предложение)

## Поиск

Основной способ найти товар - поиск по MPN (маркировке детали).
MPN нормализуется при импорте: убираются суффиксы, спецсимволы, разные форматы одного номера приводятся к одному виду.

Поиск работает на двух уровнях:
- **Meilisearch** - для UI поиска (быстрый, опечатки)
- **Postgres FTS (tsvector)** - для сложных запросов (полнотекстовый, веса A/B/C)

## Как пополняется каталог

```
Парсер (локально, Mac) → Docker PostgreSQL → npm run db:publish → Supabase (прод)
```

1. Парсер запускается локально на Mac разработчика (вне этого репо)
2. Парсер наполняет локальную PostgreSQL в Docker
3. Enrichment-пайплайн обогащает данные из Mouser/LCSC/ChipDip
4. `npm run db:publish` зеркалирует каталог в Supabase прод

Подробности:
- `docs/business/architecture.md` - архитектурные решения
- `.claude/skills/enrichment.md` - как работает enrichment
- `.claude/skills/db-publish.md` - как работает публикация

## B2B-функционал

На сайте есть B2B-витрина с оптовыми ценами и формой заявки на КП.
Заявки (`QuoteRequest`) хранятся только в Supabase проде.
При поступлении новой заявки отправляется уведомление в Telegram.
Доступ к заявкам через защищённую паролем админ-панель.
