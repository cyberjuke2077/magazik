## Что нужно для реального магазина в РФ

### 1. Юридические обязательства (БЛОКЕР)

Без этого торговать онлайн нельзя - штрафы и претензии от покупателей.

| Что | Закон | Статус |
|---|---|---|
| Реквизиты компании на сайте (ИНН, ОГРН, юр. адрес) | ФЗ-149, ПП РФ 612 | нет |
| Публичная оферта | ст. 435-437 ГК РФ | нет |
| Политика обработки персональных данных | ФЗ-152 | нет |
| Согласие на обработку ПДн при форме заявки | ФЗ-152 | нет |
| Политика Cookie | ФЗ-152 | нет |
| Условия возврата (14 дней для физлиц) | ФЗ-2300-1 | нет |

**Специфика электронных компонентов:** если продаём физлицам - возврат обязателен.
Если только юрлицам - ГК РФ + договор поставки, условия гибче.

---

### 2. Оплата (БЛОКЕР для онлайн-продаж)

Сейчас: только заявка на КП → менеджер → счёт → оплата вручную. Это работает для B2B.
Для B2C и малых B2B-заказов нужен автоматический эквайринг.

**Варианты для РФ 2026:**

| Шлюз | Комиссия | Особенности |
|---|---|---|
| ЮKassa (Яндекс) | 2.8-3.5% | лучший для ИП/ООО, МИР+Visa+MC, быстрая интеграция, есть рассрочка |
| Тинькофф Касса | 2.49-2.79% | чуть дешевле, стабильный, B2B-сплит |
| Сбербанк Эквайринг | 1.8-2.5% | дорогой API, долгое подключение |
| CloudPayments | 2.5-3.2% | хорошая документация, но выше комиссия |

**Рекомендация:** ЮKassa - самая простая интеграция, Next.js SDK есть.

**54-ФЗ (онлайн-касса) - обязателен при приёме денег от физлиц:**
- Нужна касса (облачная или физическая)
- Чек должен прийти покупателю до/в момент оплаты
- ЮKassa умеет интегрироваться с кассами (АТОЛ, Эвотор, МодульКасса)
- Если только юрлица по безналу - 54-ФЗ не нужен

---

### 3. Доставка

Сейчас: не реализовано.

| Служба | Покрытие | Интеграция |
|---|---|---|
| СДЭК | вся РФ + СНГ | REST API, хорошая документация |
| Почта России | вся РФ | API есть, но глючный |
| Boxberry | крупные города | REST API |
| Самовывоз | только свой город | без интеграции |

**Для электронных компонентов критично:** маленькие, лёгкие посылки - СДЭК выгоднее всего.

Минимум для запуска:
- Самовывоз (если есть офис/склад)
- СДЭК до ПВЗ (дешевле всего для клиента)
- Курьер по городу (опционально)

---

### 4. Реальное оформление заказа

Сейчас: есть корзина, но нет полного flow заказа.

Нужно:
- Страница оформления: адрес, доставка, оплата
- Статусы заказа: новый → оплачен → собран → отправлен → доставлен
- Email-подтверждение покупателю
- Личный кабинет (опционально на старте, но сильно помогает удержанию)

---

### 5. Авторизация покупателей

Сейчас: авторизации для покупателей нет.

Минимум для магазина:
- Регистрация по email
- Вход (email + пароль или magic link)
- История заказов в ЛК
- Сохранённые адреса

Для B2B дополнительно:
- Привязка к юрлицу (ИНН)
- Индивидуальные цены по договору

---

### 6. SEO - органический трафик в нише

Электронные компоненты хорошо ищут по MPN. Это наш главный SEO-козырь.

Сейчас:
- Нет `sitemap.xml` с товарными страницами
- Нет `schema.org/Product` разметки
- Нет нормальных title/description для товаров

Что даёт трафик в этой нише:
- `{MPN} купить` - коммерческий интент, высокая конверсия
- `{MPN} datasheet` - информационный, но лидогенерация
- `{категория} {характеристика}` - долгий хвост

**Конкуренты:** chipdip.ru, zener.ru, platan.ru - все хорошо SEO-оптимизированы.

---

### 7. Email-уведомления

Нужны минимум:
- Подтверждение заказа покупателю
- Смена статуса заказа
- (Для B2B) КП готово, ссылка на счёт

Сервисы для РФ: Unisender, Sendsay, Postmaster Mail.ru (бесплатно до 5к/день).
Или просто SMTP через Яндекс 360.

---

### 8. Специфика аудитории

**B2B (основная аудитория):**
- Покупает по безналу, нужен счёт и УПД/накладная
- Ценит скорость ответа менеджера
- Смотрит на наличие и реальные сроки поставки
- Торгуется на объёме

**B2C (инженеры, радиолюбители):**
- Платит картой, хочет быстро
- Смотрит на цену + доставку
- Хочет подбор аналогов если нет в наличии

## Приоритизация по этапам

### Этап 0 - Юридика (СЕЙЧАС, до любого трафика)
Без этого нельзя пускать людей на сайт. Делается за 1-2 дня.
- Страница с реквизитами компании
- Публичная оферта (шаблон + адаптация под наш ассортимент)
- Политика ПДн + чекбокс в форме заявки
- Условия возврата/обмена

### Этап 1 - B2B онлайн (2-4 недели)
То, что уже почти работает - доделать до конца.
- Полный flow заявки на КП (форма → статусы → ответ менеджера)
- Email-уведомления покупателю
- Реквизиты для безналичной оплаты
- SEO-основа (sitemap, schema.org, title/description)

### Этап 2 - Онлайн-оплата (4-8 недель)
- Интеграция ЮKassa
- Оформление заказа с оплатой
- Онлайн-касса (если есть физлица)
- Статусы заказа + уведомления

### Этап 3 - Доставка (параллельно или после Этапа 2)
- СДЭК API - расчёт стоимости и оформление отправки
- Самовывоз
- Трекинг в ЛК

### Этап 4 - Личный кабинет (после стабилизации)
- Регистрация/вход
- История заказов
- Сохранённые адреса
- B2B: привязка к юрлицу, индивидуальные цены

---

## Главный риск

Сайт сейчас - это витрина + форма заявки. Реальная торговля идёт через менеджера.
Это нормально для старта, но нужно понимать: **Этап 0 + Этап 1 можно сделать за месяц и уже полноценно работать**.
Онлайн-оплата (Этап 2) нужна только если хотим автоматизировать розницу.
