Для secret-scan используй отдельные `-e` паттерны без вложенных кавычек.

**Why:** составное регулярное выражение с несколькими типами кавычек сломало shell-команду и не выполнило проверку.

**How to apply:** перед добавлением локальных файлов в Git запускай `rg -l` с отдельным `-e` для каждого формата ключа и выводи только имена файлов.
