---
name: verify-next-dev-before-browser
type: feedback
---
Перед browser QA проверить существующий Next.js dev-процесс и доступность его
origin, не запускать второй сервер в том же checkout поверх `.next` lock.

**Why:** повторный `npm run dev` сообщил `Ready` на запасном порту, затем завершился
из-за уже работающего процесса; вкладка осталась на внутренней error-странице.

**How to apply:** сначала проверить текущий PID, порт и HTTP-ответ. Если origin
изменился после сетевой ошибки, открыть чистую вкладку вместо навигации из
внутренней `data:`-страницы браузера.
