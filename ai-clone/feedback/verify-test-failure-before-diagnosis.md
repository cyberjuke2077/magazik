Перед объявлением пользовательского бага прочитать точную ошибку теста и
проверить наблюдаемое поведение; название упавшего теста не является диагнозом.

**Why:** 20 сентября агент назвал падение E2E с повреждённой корзиной поломкой
страницы. Причиной оказалась неоднозначность CSS locator: в streaming HTML
Next.js присутствовали две шапки. После ожидания готового каталога и проверки
видимого banner сценарий прошёл на desktop и mobile без изменения приложения.

**How to apply:** сначала error-context/trace, затем конкретная причина.
До подтверждения сообщать о падении проверки, не об установленном дефекте.
