---
name: windows-spawn-npm-cmd
type: feedback
---
На Windows не запускать `npm.cmd` прямым `spawn`; использовать `ComSpec /d /s /c`
только с фиксированными внутренними аргументами без пользовательского ввода.

**Why:** integration-тесты получили `spawn EINVAL`, а временный `shell: true`
устранил ошибку, но вызвал предупреждение Node о небезопасной конкатенации.

**How to apply:** при запуске npm из Node выбирать `npm` на POSIX и `ComSpec` с
фиксированной командой на Windows. Не подставлять в командную строку внешние
значения, пути загрузок или пользовательский текст.
