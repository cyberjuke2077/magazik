# Эталон витрины

Основа: только три товара `prisma/seed-local-mvp.ts`, три категории и три
производителя, без ProductImage. Даты товаров фиксированы в январе 2020:
порядок и бейдж «Новинка» не меняются от даты запуска. `visual-fixture.ts`
проверяет состав, цены, остатки, минимальный заказ и даты перед снимками.

Эталоны 2026-09-20 сняты на macOS / Chromium из установленного Playwright,
1440x1100 desktop и 390x844 mobile, ru-RU, Europe/Moscow, scale 1.
Они фиксируют согласованный запрос на обновление дизайна, используя прежний
детерминированный seed. В снимках включён reduced motion и дожидаемся загрузки
изображений ниже первого экрана. Движение отдельно проверяется в браузере.
Dev-индикатор Next скрыт только на снимке; остальные элементы не маскируются.
Рендер на Linux может отличаться шрифтами: не обновлять macOS-эталон из CI.
CI запускает всю функциональную матрицу; визуальная приёмка пока локальная.

На отдельной локальной БД задать POSTGRES_* через окружение, затем:

```sh
npm run db:migrate:local
npm run db:seed:local-mvp
npm run test:e2e:local
```

Обновлять снимки только после просмотра expected/actual и установления причины:

```sh
npm run test:e2e:local -- --grep 'visual baseline' --update-snapshots
```

После обновления нужен обычный запуск без `--update-snapshots`. Guard fixture
не очищает и не исправляет БД: при лишних данных он падает, защищая рабочий каталог.
