# Windows runner для массового parser/enrichment

## 1. Задача

Проверить, готов ли parser к массовому запуску на Windows по всему приватному
списку заказчика, и перенести рабочий launcher из старого конфликтующего PR #13.

## 2. Как решали

- Проверили текущий `main`, resume, TUI, npm-команды и старые Windows-файлы.
- Не делали cherry-pick старого смешанного коммита.
- Исправили живой размер run и подсчёт только терминальных результатов.
- Связали `q` с graceful shutdown pipeline и закрытием браузеров.
- Сделали resume строгим и независимым от freshness-фильтра.
- Добавили локальные npm-команды, installer, меню, блокировку сна и отчёт
  unresolved.
- Добавили GitHub Actions smoke на `windows-latest` с PowerShell parser,
  unit-тестами, TypeScript и input-only dry-run.

## 3. Результат: частично

Кодовая готовность Windows runner подтверждена. PR #23 смержен с merge SHA
`42841db523035c2d5f59ee32e42910adbc6a9e0d`. Локально прошли 307 unit-тестов,
TypeScript, lint, production build и dry-run с пустым `DATABASE_URL`. Отдельный
GitHub Actions run `33020672898` успешно прошёл на `windows-latest`: PowerShell
syntax, launcher-тесты, TypeScript и input-only dry-run зелёные.

Реальные источники, локальная рабочая БД на целевой Windows, production
Supabase, R2 и `db:publish` не запускались.

Полный приватный набор отсутствует в Git. На Windows его нужно скопировать
отдельно и сначала подтвердить dry-run: 11 файлов, 75 706 строк, 17 пропущенных
строк и 67 200 уникальных MPN. Физический live-пилот на целевой Windows-машине
остаётся обязательным перед многонедельным run.

## 4. Что можно было лучше

Старый launcher зависел от npm-команд, которых не было в `main`, а текущий TUI
показывал захардкоженный размер списка и закрывался отдельно от pipeline. Windows
runner нужно было переносить вместе с проверкой зависимостей и resume-контракта,
а не как набор `.cmd` и `.ps1` файлов.

## 5. Изменения во втором мозге

- Windows зафиксирован как поддерживаемая локальная машина оператора.
- Зафиксирован строгий resume по незавершённому журналу.
- Зафиксировано различие между обработанным и найденным MPN.
- Добавлена пошаговая инструкция `docs/windows-parser-setup.md`.
