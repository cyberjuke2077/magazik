# Совместная работа с Codex - 2026-07-26

## 1. Задача

Сделать повторяемую и безопасную инициализацию Codex для соразработчика, работающего с тем же private GitHub-репозиторием.

## 2. Как решали

Добавили общий протокол `docs/codex-collaboration.md`, закрепили его в `AGENTS.md` и onboarding. Уточнили границы автоматического контекста Codex, Git-flow, handoff и запреты для production и секретов.

## 3. Результат

Да. Соразработчик может клонировать репозиторий, открыть его в Codex, получить project instructions автоматически и вести задачу в отдельной ветке с Pull Request в `main`.

## 4. Что можно было лучше

Раньше правила о versioned втором мозге и legacy collector остались в нескольких документах противоречивыми. Их синхронизировали с текущей private-repo политикой.

## 5. Изменения во втором мозге

`AGENTS.md` теперь задаёт безопасный protocol совместной работы Codex. Второй мозг, планы и ретроспективы хранятся в private Git, а секреты и локальные данные остаются вне него.
