# Локальное завершение и подготовка переноса

## Задача

Доделать оставшееся после adversarial review. В процессе владелец подтвердил
направление переноса в РФ, отсутствие сервера и решение пока не выходить в prod.

## Как решали

- `aef09dd`: gzip/deflate/br с отдельными лимитами 8 MiB на сеть и распаковку,
  общим timeout/cancellation и обработкой повреждённых потоков.
- `95447ae`: фиксированные даты seed, guard состава/цен/остатков тестового
  каталога, восемь проверенных визуальных эталонов, весь функциональный E2E в CI.
- `9d72ca9`, `0646075`: будущий прямой ingress nginx + loopback systemd template,
  реальная локальная проверка поддельных forwarding headers и синтаксиса TLS.
- `6b125a5`: розница/опт с условиями показаны отдельно; убраны неподтверждённые
  сроки, скидки и «ХИТ». Новые desktop/mobile снимки просмотрены.
- Read-only сверка GitHub и Supabase показала старый deployment/main `2bd5d94`,
  PostgreSQL 17.6 в eu-west-3 и три отсутствующие новые миграции.

## Результат

Локальный пакет завершён. Ветка `codex/adversarial-review-20260917`, вершина
кодовой части `6b125a5`. После неё менялись только документы.

Проверки: 52 файла / 420 unit; 9 readiness integration; 5 real TLS integration;
71 E2E passed / 1 предусмотренный skip на mobile, включая 8 visual assertions
без обновления эталонов. ESLint, TypeScript, git diff --check и production build
webpack успешны, 33 статические страницы. Локальный nginx test успешен.
BrowserAct открыл главную в чистом профиле; сессия закрыта.

Без push, PR, миграций production, deployment, публикации каталога и внешних
уведомлений. Локальные тесты не принимают production: не проверены целевой
firewall/systemd/TLS, restore реальных данных, runtime RLS и настоящая доставка.
Сервера нет, дальнейшая выкладка отложена владельцем.

## Что можно было лучше

Нужно было проверить тип параметра Playwright до пересоздания эталонов: `style`
игнорировался assertion API, TypeScript обнаружил это; исправлено на `stylePath`.
Не повторять эту ошибку, проверять реальный PNG. В UI UX Pro Max не нашлось
релевантного правила про коммерческие обещания; подписи исправлены по фактической
модели проекта, а не на основании выдуманного результата поиска skill.

## Изменения во втором мозге

Обновлены текущая матрица закрытия, архитектура, продукт и оба INDEX.

Playwright сохранено в `ai-clone/feedback/verify-playwright-assertion-options.md`.
Глобальная память не менялась.
