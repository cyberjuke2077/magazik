# Повторная проверка перед закрытием release-хвостов

## Задача

Продолжить подготовленный выпуск всей ветки по просьбе владельца.

## Как решали

Прочитаны актуальный handoff и протокол совместной работы. Обновлены remote
refs, проверены PR #26 и CI на `528ddbe`, состояние целевой Supabase и
checksum трёх подготовленных миграций. Production проверялся только чтением.

## Результат

Частично: кодовый кандидат и CI подтверждены, main остаётся на `2bd5d94`.
Для backup/restore, миграций и передачи секретов повторно запрошены отдельные
разрешения, которых не хватило автоматической проверке в прошлой сессии.
До ответа backup, DDL, настройки, merge и deployment не выполняются.
Следующий шаг - обработать ответы и продолжить по release handoff.

## Что можно было лучше

Supabase CLI не находится в текущем PATH. Перед разрешённым backup проверить
место установки и help фактической версии; наличие CLI в прошлой сессии
не гарантирует доступность команды в новой.

## Изменения во втором мозге

Свежая проверка записана в `docs/operations/full-branch-release-2026-09-20.md`.
Новых правил для AGENTS.md не требуется: ограничения Git sandbox и проверка
доступности инструментов уже предусмотрены существующими правилами.
