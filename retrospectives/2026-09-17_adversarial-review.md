# Адверсариальное ревью - 2026-09-17

## Задача

Проверить ошибки кода, безопасность и готовность магазина к коммерческому запуску с позиции покупателя.

## Как решали

Сверили commit с GitHub main, изучили обработку заявок, админку, поиск, корзину, импорт и публикацию. Прошли публичный путь покупателя в отдельной BrowserAct-сессии. Проверили зависимости через npm audit и advisory разработчиков, Supabase target/регион/grants/RLS через read-only MCP. Для повтора заявок, minOrder и CSV исполнили реальный код с изолированными подменами БД и внешних интеграций.

## Результат

Ревью завершено: [отчёт с 15 находками и критериями исправления](../docs/operations/adversarial-review-2026-09-17.md). Приложение не исправлялось. Пройдены 307 unit-тестов, lint и TypeScript. Обнаружены три P1: уязвимые Next.js/sharp, противоречие политики ПДн фактическому региону, стирание production-цен и остатков локальной публикацией.

Проверенный исходный commit: `2bd5d94480eb24e359a0bba10c232699ab5b88b5`. Ветка отчёта: `codex/adversarial-review-20260917`. Push и deployment не выполнялись. Первый следующий шаг - обновление уязвимых зависимостей с проверками и отдельное решение владельца о размещении ПДн.
