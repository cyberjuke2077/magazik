# Перенос проекта и второго мозга в GitHub

## Цель

Перенести в private GitHub-репозиторий `cyberjuke2077/magazik` весь версионируемый код, второй мозг, проектные инструкции и доступные материалы parser/collector без секретов и runtime-артефактов.

## Фазы

- [x] Новый private-репозиторий создан, `origin` перевязан, текущая история опубликована в `main`.
- [x] Инвентаризированы ignored-материалы и проверены кандидатные документы на типовые секреты.
- [x] Версионировать второй мозг, инструкции и документацию по Git workflow.
- [x] Версионировать доступные материалы parser/collector и parsed CSV.
- [ ] Зафиксировать безопасную границу: env, runtime-конфиг, SQLite, логи, кэши и архивы БД не публикуются.
- [x] Восстановить последний исходный код collector из истории Git в `tools/collector-legacy`.
- [ ] Закоммитить, запушить и сверить удалённые refs с локальным HEAD.

## Граница переноса

В Git идут исходники, документация, планы, ретроспективы, ai-clone, project skills и небольшие проверяемые sample-данные. Не идут `.env*`, `config.yaml`, SQLite progress/backup DB, логи, кэши, виртуальные окружения, `node_modules` и generated output. Эти данные нужно хранить в зашифрованном backup/vault, а не в Git.
