# Редизайн витрины под премиум-B2B (Stripe/Linear/Mouser)

Дата: 2026-06-23
Ветка: `redesign/storefront-2026-06`
Референс: скриншот владельца + Mouser/DigiKey/TME/Stripe/Vercel/Linear.

## Контекст и решения

- Текущий слой витрины - плотный «индустриально-острый» ChipDip-стиль (радиусы 6-12px,
  Shape Lock). Владелец развернул направление: **премиум-B2B**, радиусы 16-24px, много
  воздуха, мягкие тени, крупная типографика, electric-blue (`azure #0066cc` уже есть).
- Охват: **весь сайт** (решение владельца). UI-кит - на своей токен-системе (без shadcn:
  Tailwind v4 + расширенные токены + переиспользуемые классы/компоненты). Lucide - иконки.
- Принципы: не «нейрослоп», человеческая рука, ясность (понятно «и ребёнку, и дедушке»),
  анимации в меру на ключевые секции.
- Hero: оставляем **слайдер** (не поиск по центру). Поиск живёт в шапке/sticky-nav.

## Не сломать (DOM-зацепки)

- `data-cart-icon` (sticky-nav) - fly-to-cart.
- `data-add-to-cart-block` (страница товара) - sticky-add-bar IntersectionObserver.
- URL-параметры каталога (`category/sort/view/limit/page`).
- Хранилище `electromagaz_cart` (корзина = список запроса).
- Контакты/реквизиты - только из `src/lib/company.ts`.
