# Редизайн витрины Electromagaz

Дата старта: 2026-06-15. Референс: чистый плотный B2B e-commerce (тип ElecTrade).
Методичка-ограничители: `docs/redesign-guardrails.md` (зацепки нельзя ломать).

## Design Read

Redesign (overhaul разрешён) B2B-витрины электронных компонентов для инженеров-снабженцев.
Язык: технический, trust-first, плотный. Tailwind v4 tokens + Geist/Geist Mono + сдержанная анимация.

Дилы: `DESIGN_VARIANCE 6` · `MOTION_INTENSITY 4` · `VISUAL_DENSITY 6`.

## Решения по продукту (согласовано с владельцем 2026-06-15)

- Цены **публичные** (не «по запросу»). Кнопка «в корзину» + «Запросить КП» как доп.
- Объём первой итерации: **дизайн-система + главная** как эталон.
- Близость к референсу: **свобода по вкусу**, берём язык, не клон.
- Dark mode: **НЕ в этой итерации** (light-only осознанно, бэклог).

## Что нельзя ломать (из методички)

- DOM-зацепки: `data-cart-icon`, `data-add-to-cart-block`, URL-параметры каталога (`?category=`).
- localStorage: `electromagaz_cart`, `electromagaz:compare` — не переименовывать.
- Контакты/реквизиты — только из `src/lib/company.ts`.
- Server actions, хуки (`use-cart`, `use-compare`), SEO (`generateMetadata`, JSON-LD).
