# B2B MVP Electromagaz и последующие этапы

Дата: 2026-07-31  
Статус: `[ ]` к выполнению  
Владелец продукта: владелец Electromagaz  
Техническое исполнение: Codex под руководством владельца

## Цель

Запустить устойчивую B2B-витрину электронных компонентов, в которой покупатель
может найти товар, изучить карточку, собрать корзину, отправить заявку на КП, а
менеджер может получить и обработать эту заявку.

MVP не должен ждать полноценной онлайн-оплаты, доставки и личного кабинета.
Эти возможности идут отдельными этапами после подтверждения работоспособности
основной B2B-модели.

## Граница MVP

В MVP входят:

- публичная витрина и адаптивная навигация;
- каталог, категории, фильтры и поиск по MPN;
- карточка товара с производителем, характеристиками, изображениями и datasheet;
- цена, оптовая цена и наличие там, где данные подтверждены;
- корзина с количеством позиций;
- одна каноническая форма заявки на КП;
- отдельная рабочая форма оптового лида;
- сохранение заявок и лидов в Supabase;
- уведомление менеджера;
- защищённая админ-панель для обработки заявок и управления ценами;
- юридические страницы с реальными реквизитами;
- основной домен, HTTPS, мониторинг и резервное копирование;
- воспроизводимый выпуск через Preview, Pull Request и production deploy.

В MVP не входят:

- приём онлайн-оплаты;
- онлайн-касса и электронные чеки;
- автоматическая интеграция со СДЭК;
- реальная регистрация и личный кабинет;
- история заказов и сохранённые адреса;
- интеграция с 1С;
- мобильное приложение;
- маркетплейсы.

## Порядок выполнения

```text
Продуктовые решения
  -> Юридика
  -> Production-инфраструктура
  -> Каталог и R2
  -> Полный путь заявки
  -> Качество и безопасность
  -> Preview и приёмка
  -> Production MVP
  -> Стабилизация
  -> Личный кабинет, оплата и доставка
```

Юридика и инфраструктура могут выполняться параллельно. Каталог можно готовить
параллельно, но массовый enrichment и production-публикация начинаются только
после подтверждения входного набора, бакета и целевой БД.

## Проверочные команды

```bash
npm test
npm run test:integration
npm run lint
npm run build
npm run test:e2e
npm run enrichment:status
npm run db:stats
```

Команды enrichment и `db:publish` не входят в обычную проверку кода. Реальный
запуск выполняется отдельно, с `--dry-run`, явным `--limit`, проверенным входным
файлом и подтверждённой целевой базой.
