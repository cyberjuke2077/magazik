# Windows parser runner

Дата: 2026-08-14

## Цель

Подтвердить реальную работу enrichment-парсера на контролируемом пилоте и
подготовить запуск на чистой Windows без необходимости вручную собирать команды.

## Стоп-условия

- Не запускать полный список до успешного пилота и ручной проверки карточек.
- Не подключать Windows parser напрямую к production Supabase для первого запуска.
- Не публиковать каталог через `db:publish` в рамках проверки parser runner.
- Не хранить credentials в Git, launcher или инструкции.

## Результат

- Dry-run: 11 файлов, 75 706 строк, 17 пропущено, 67 200 уникальных MPN.
- ChipDip health-check прошёл через CloakBrowser с Playwright API.
- Живые карточки `ADAU1701JSTZ` и `AD1940YSTZRL` записаны в локальную БД.
- Пилот выявил и исправил внутренний код производителя `AD1`.
- Windows launcher подготовлен, но физический запуск на Windows остаётся
  отдельной device-проверкой после клонирования репозитория на ту машину.
- Production Supabase и `db:publish` не затрагивались.
- Код parser/TUI зафиксирован в `ab406c9`, Windows launcher - в `4e056f4`.
- Git handoff выполняется в существующий draft PR #13 ветки
  `codex/mpn-catalog-enrichment`.
