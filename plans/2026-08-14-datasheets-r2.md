# Datasheets to R2

Дата: 2026-08-14

## Цель

Перестать хранить в каталоге нестабильные внешние PDF-ссылки. Бинарные PDF
должны находиться в Cloudflare R2, а PostgreSQL должна хранить только метаданные
и постоянный публичный R2 URL.

## Фазы

- [x] Перевести persistence с прямой записи внешних URL на постановку в очередь.
- [x] Реализовать безопасное скачивание PDF с лимитом, timeout и SSRF-проверкой.
- [x] Реализовать content-addressed загрузку PDF в R2.
- [x] Добавить resumable worker и backfill старых внешних ссылок.
- [x] Добавить команды npm и пункт Windows-меню.
- [x] Выполнить unit-тесты и dry-run на локальной БД.
- [x] Выполнить live-пилот одного PDF: источник -> R2 -> локальная БД.
- [x] Проверить production build, обновить архитектуру и второй мозг.
- [x] Commit, push и обновление draft PR #13.

## Стоп-условия

- Не хранить PDF bytes или base64 в PostgreSQL.
- Не удалять рабочую внешнюю ссылку до успешной загрузки хотя бы одного PDF.
- Не принимать HTML, слишком большой файл или URL внутренней сети как PDF.
- Не публиковать локальную БД в production через `db:publish` в этой задаче.
- Не запускать массовый backfill до успешного пилота одного реального файла.
