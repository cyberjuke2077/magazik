## Решение владельца

Полностью перестроить публичную витрину Electromagaz по композиции и UX-паттернам
DNS Shop. Переносим плотность, сетку, иерархию, навигацию и поведение экранов.
Логотип, маскот, рекламные материалы, тексты и товарные данные DNS не копируем.

## Design Read

Полный визуальный overhaul B2B-магазина для инженеров, закупщиков и радиолюбителей.
Язык интерфейса плотный, утилитарный и коммерческий. В основе Tailwind CSS v4,
существующие React-компоненты и текущая икон-система Lucide.

- `DESIGN_VARIANCE: 3` - предсказуемая сетка и стабильное расположение действий.
- `MOTION_INTENSITY: 4` - функциональный autoplay hero, hover, active,
  раскрытие меню и обратная связь с обязательным reduced-motion.
- `VISUAL_DENSITY: 9` - максимум полезных данных без рекламного шума.
- Тема: только светлая. Это осознанное соответствие референсу, dark mode не входит в задачу.
- Новую UI-библиотеку не добавлять.
- Server Components по умолчанию. Client Components только для интерактивных листьев.

## Целевой результат

Пользователь с первого экрана должен уметь:

1. Открыть каталог или ввести MPN.
2. Увидеть категорию, наличие, цену и основные характеристики без лишних переходов.
3. Добавить товар в список запроса или сравнение.
4. На мобильном пройти тот же путь одной рукой.
5. Отправить запрос на КП без потери данных и без изменения текущей бизнес-логики.

## Целевой дизайн-фундамент

### Семантические токены

Точные значения уточняются при визуальной сборке, роли фиксируются заранее:

- `--canvas` - нейтральный светло-серый фон страницы.
- `--surface` - белые рабочие поверхности.
- `--surface-muted` - фон тулбаров, пустых состояний и вторичных панелей.
- `--text-primary` - основной графитовый текст.
- `--text-secondary` - подписи и вторичные характеристики.
- `--border-subtle` - границы и разделители.
- `--link` - синий цвет навигации и уточняющих действий.
- `--action` - оранжевое главное коммерческое действие.
- `--danger` и `--success` - только семантические состояния.

Оранжевый не использовать для декора. Он принадлежит кнопке покупки, каталогу и
другим главным коммерческим действиям. Синий не конкурирует с CTA.

### Геометрия

- Рабочий контейнер: максимум 1440 px.
- Боковые поля desktop: 24-32 px.
- Боковые поля mobile: 12-16 px.
- Основной радиус панелей: 12 px.
- Крупные промо-поверхности: максимум 16 px.
- Контролы: 8-10 px.
- Pills только для чипов и компактных переключателей.
- Тени минимальные. Иерархия строится фоном, границами и группировкой.

### Типографика

- Onest используется для интерфейса, описаний, контролов, цен и числовых значений.
- Wix Madefor Display используется для H1-H4 и коротких витринных заголовков.
- Geist Mono используется только для MPN, артикула и технических идентификаторов.
- Desktop body: 14-16 px.
- Товарные характеристики: 12-14 px.
- H1 витрины: 28-36 px, без лендингового масштаба.
- Заголовки не занимают более двух строк на целевом viewport.

### Слои

- `0` - обычный контент.
- `10` - sticky-панели внутри страницы.
- `20` - desktop-шапка и mobile bottom nav.
- `30` - мегаменю и dropdown.
- `40` - drawer и modal.
- `50` - toast и критичная обратная связь.

Произвольные `z-[100]` после миграции не оставлять.

## Пересобрать главную `[x]`

Цель: заменить длинный премиум-лендинг на компактную коммерческую главную.

Порядок блоков:

1. Общая оболочка и поиск.
2. Ручной слайдер из реальных материалов Electromagaz без CTA внутри баннера.
3. Быстрый вход в ключевые категории.
4. Популярные или новые товары с реальными данными и изображениями R2.
5. Бренды.
6. Недавно просмотренные товары, если они есть.
