# Завершение проверок и подготовка переноса

Пользователь выбрал направление переноса в российскую инфраструктуру.
Провайдер, сервер, домен, бюджет и доступы пока не определены.
Владелец затем уточнил: production сейчас преждевременен. Перенос отложен,
текущий объём - локальное завершение и подготовительные материалы.

- [x] Сверить GitHub deployment и migration history действующей БД read-only.
- [x] Поддержать HTTP-сжатие изображений с лимитами до и после распаковки.
- [x] Устранить зависимость визуальных тестов от случайного каталога.
- [x] Прогнать полный локальный набор проверок: 420 unit, 9 readiness,
      5 TLS, 71 E2E + 1 skip, 8 visual внутри E2E, nginx, lint, TS, webpack build.
- [x] Подготовить воспроизводимый self-hosting ingress и порядок переноса.
- [x] Убрать неподтверждённые сроки, скидки и «ХИТ» на карточках главной.
- [x] Зафиксировать точные результаты и оставшиеся действия владельца.
- [ ] Отложено владельцем: после отдельного решения и выбора сервера выполнить
      backup/restore и приёмку целевого контура.

Production остаётся на прежнем коде. Подготовка конфигурации не означает
перенос данных или подтверждение размещения в РФ.

Итоговый [handoff следующей сессии](../docs/operations/session-handoff-2026-09-18.md)
содержит SHAs, проверки, ограничения и первый следующий шаг. Локальные пункты
плана завершены; инфраструктурный пункт сознательно отложен владельцем.
