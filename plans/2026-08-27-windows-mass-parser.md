# Массовый запуск parser/enrichment на Windows

Дата: 2026-08-27
Статус: код готов, ожидается физический live-пилот на Windows

## Цель

Подготовить актуальный `main` к длительному локальному запуску всего списка
заказчика на Windows с dry-run, пилотами, журналом, безопасной остановкой и
возобновлением после перезапуска.

- [x] Проверить текущие команды, resume-контракт и старый Windows launcher.
- [x] Исправить живое обновление TUI и безопасную остановку клавишей `q`.

- [x] Запустить unit-тесты, TypeScript, lint и production build.
- [x] Зафиксировать ветку, commit и PR.

## Стоп-условия

- Не запускать реальные внешние источники с этой Mac-машины.
- Не писать в production Supabase, Cloudflare R2 и не запускать `db:publish`.
- Не коммитить входные файлы заказчика, `.env`, логи и runtime-state.
- Не обещать, что каждый MPN будет найден: полный проход гарантирует обработку,
  а не наличие карточки у внешних источников.
- Физический запуск на Windows считать подтверждённым только после Windows CI и
  отдельного пилота на целевой машине.

## Исходные факты

- Старый launcher находится только в конфликтующей ветке PR #13 и вызывает
  отсутствующие в текущем `main` npm-команды.
- Ранее зафиксированный набор заказчика: 11 файлов, 75 706 строк, 17 пропущенных
  строк и 67 200 уникальных MPN. Сами приватные файлы в Git не хранятся.
- В текущем checkout доступен только маленький синтетический input для dry-run;
  полный набор нужно скопировать на Windows отдельно.
