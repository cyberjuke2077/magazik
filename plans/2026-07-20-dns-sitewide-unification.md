# Полная унификация витрины в стиле DNS

Дата: 2026-07-20
Статус: реализовано и проверено
Ветка: `codex/dns-storefront-redesign`

## Решение владельца

Текущий редизайн не считать финальным. Вся публичная витрина должна выглядеть как
единый интернет-магазин по композиционным и UX-паттернам DNS. Фирменный оранжевый
DNS не переносим. Главное действие Electromagaz - электрический синий.

Пользовательский термин `Запрос` заменить на `Корзина`. Технические маршруты,
storage key `electromagaz_cart`, server actions, схема БД и формат данных не менять.

## Сохраняемые контракты

- Все публичные маршруты и query-параметры каталога.
- `electromagaz_cart`, `electromagaz:compare`, `electromagaz:recently-viewed`.
- События `cart:change` и `compare:change`.
- `data-cart-icon` и `data-add-to-cart-block`.
- Server Actions КП и оптовой формы.
- JSON-LD, metadata, canonical, sitemap и robots.
- Контакты и реквизиты только из `src/lib/company.ts`.
