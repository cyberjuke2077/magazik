# Безопасное массовое обогащение каталога

## Цель

Подготовить enrichment к длительной обработке выбранной части каталога без
повторного сбора свежих данных, с переносимой конфигурацией, безопасными
интервалами, ценой, классификацией и полезным сравнением товаров.

## Решения

- Входной контракт заказчика - только список MPN. Бренд и все поля
  товарной карточки определяются по точному совпадению во внешних
  источниках.
- Supabase хранит память о собранных карточках через `Product`,
  `enrichmentStatus`, `lastEnrichedAt` и field provenance.
- По умолчанию новый run пропускает свежие карточки `complete`. Явное
  обновление выполняется только через `--force-refresh`.
- Несекретная конфигурация хранится в `config/enrichment.json`. Ключи,
  credentials и proxy URL остаются только в env.
- Интервал каждого источника задаётся диапазоном. После блокировок и сетевых
  ошибок применяется ограниченный backoff.
- Цена источника записывается только в пустое поле или поверх предыдущей цены
  parser-origin. Ручная цена без provenance не перезаписывается.
- Для сайта сохраняется исходная категория, но итоговый `categoryId`
  определяется контролируемой таксономией Electromagaz.
- «Самообучение» не является неконтролируемым ML. Общая база предотвращает
  повторный сбор, а новые проверенные соответствия категорий добавляются в
  versioned-конфигурацию.
- Сравнение использует актуальные данные из БД, нормализует названия
  характеристик и явно сообщает о лимите.

## Ограничения запуска

Массовый run не запускается до получения выборочного файла владельца и пилота.
Полный каталог ChipDip проекту не требуется. Перенос изображений и datasheet
не запускается до отдельного подтверждения готовности бакета.

## Результат

Инфраструктура реализована и проверена. 2026-08-14 входной контракт
расширен до списка только с MPN, dry-run изолирован от БД и сети. Пилот
LCSC на трёх локальных позициях завершён без ошибок: все три карточки стали
`complete`, добавлены 47 характеристик, 3 datasheet и 3 изображения.
Массовый run ожидает фактический список MPN заказчика.
