Модуль контроля доступа RFID-RC522 v2 с индикацией Access Denied

Артикул: RFID-RC522-AD
390 ₽ В наличии: 200+ шт.

Описание

Модуль контроля доступа на базе чипа MFRC522 с двумя светодиодами — зелёный сигнализирует Access Granted (доступ разрешён), красный — Access Denied (доступ запрещён). Работает по протоколу SPI, идеально подходит для построения самодельных СКУД на Arduino, ESP32, Raspberry Pi.

В прошивке-примере уже зашита логика «карта в белом списке → Access Granted, иначе → Access Denied». Алгоритм можно расширять под собственные сценарии.

  • Чип: NXP MFRC522
  • Частота: 13.56 МГц
  • Интерфейс: SPI
  • Питание: 3.3 В
  • Светодиоды: Access Granted / Access Denied
  • Антенна: встроенная PCB

Где применяется

Модули с индикацией access denied часто используются в учебных проектах по построению охранных систем и в прототипах умного дома. На странице ниже можно скачать пример скетча, который реализует поведение «access denied» для неизвестных карт.
