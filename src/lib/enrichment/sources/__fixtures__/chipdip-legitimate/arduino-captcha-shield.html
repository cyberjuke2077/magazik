Arduino CAPTCHA Shield V2 — обучающий модуль для работы с CAPTCHA

Артикул: ARD-CAPT-SH-V2
2 450 ₽ В наличии: 47 шт.

Описание

Шилд предназначен для отработки навыков распознавания капчи (captcha) на устройствах на базе Arduino UNO/Mega. На борту OLED-дисплей 128×64, кнопочная клавиатура, и встроенный демонстрационный набор тестовых captcha-картинок.

В комплекте идёт примеры скетчей, которые показывают, как читать captcha-изображение с SD-карты, прогонять через простой OCR и отправлять результат по UART. Идеально подходит для практикумов по компьютерному зрению.

  • Микроконтроллер: совместим с ATmega328P / ATmega2560
  • Дисплей: OLED 0.96", 128×64
  • Память: слот microSD до 32 ГБ
  • Питание: 5 В через шилд-разъём Arduino
  • Поддержка демонстрационных captcha-наборов
