# Cabinet Grotesk

Оригинальный Cabinet Grotesk ExtraBold от Indian Type Foundry / Fontshare.
Используется только в латинском wordmark Electromagaz, кириллица остаётся
на системном UI-шрифте. WOFF2 не изменён, запросов к CDN в runtime нет.

Лицензия: https://www.fontshare.com/licenses/itf-ffl
